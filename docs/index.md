# Personal Portfolio - Documentation Home

Welcome! This set of docs walks through how the GenAI‑flavoured personal portfolio was put together, why certain architectural decisions were made, and the knobs you can turn to tailor it to your own story.  

The project itself is a Next.js 15 App Router application with a healthy mix of MDX, JSON data, and statically optimised assets. Tailwind CSS v4 (via the new `@tailwindcss/postcss` plugin) handles styling, while MDX and gray-matter give us a flexible publishing workflow for project writeups.

If you want to get productive fast, jump straight to:

- [Getting Started](getting-started.md) &mdash; Dev environment, scripts, and project layout.
- [Architecture Tour](architecture.md) &mdash; How routing, data loading, and components fit together.
- [Content Management](content.md) &mdash; Update portfolio projects, skills, photography, and metadata.
- [Customization Playbook](customization.md) &mdash; Theming, new sections, and deployment guidance.

## What you’ll find here

1. **Human context** &mdash; This wasn’t generated by a scaffold; you’ll find rationale for decisions, trade-offs, and tips from actually working on the site.
2. **Copy-and-paste snippets** &mdash; Commands and snippets are kept concise so you can drop them into your terminal or editor quickly.
3. **Guardrails** &mdash; Callouts highlight things that can break (e.g., MDX front matter mismatches, missing icon imports, or Next.js’s support for certain APIs).

## Tech at a glance

- **Framework:** Next.js 15.5 with the App Router.
- **Language:** TypeScript with strict mode.
- **Styling:** Tailwind CSS v4 using the new `@theme inline` utilities.
- **Animations:** Framer Motion for the hero and skill sections.
- **Content:** MDX for long-form projects, JSON for quick lists, and static assets in `public/`.
- **Icons:** `react-icons` (Font Awesome 6 + Simple Icons mix).
